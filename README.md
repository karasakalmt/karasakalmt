### About

I've been building stuff for 7+ years. I started out in FinTech, went deep into Web3 (including work on Ethereum's [Elixir consensus client](https://github.com/lambdaclass/lambda_ethereum_consensus) with the LambdaClass team), and these days I spend my time shipping products at First Point:

- 📱 **Mobile apps & games**: React Native / Expo and native Swift, from everyday utilities to word puzzles
- 🤖 **Practical AI**: MCP integrations, agents and AI features built for real people, not demos
- ⛓️ **Blockchain, where it fits**: know-how I reach for only when it genuinely helps
